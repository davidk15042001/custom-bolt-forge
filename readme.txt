Industrial B2B WordPress theme with an editable fastener catalog, bilingual content and a native RFQ workflow.

== Description ==

Xiangjinxin Industrial is a standalone classic WordPress theme built for industrial fastener manufacturing, wholesale, project supply and drawing-based custom parts.

Features include:

* Responsive product, industry, company and RFQ templates
* 42-product starter catalog with 9 categories
* English and Chinese content switching
* Product/BOM/drawing/project/distributor RFQ forms
* Attachment validation, nonce protection, honeypot and rate limiting
* Browser-based RFQ list connected to the contact form
* Customizer settings for branding, design, contact details, WhatsApp and RFQ delivery
* Local Barlow, Barlow Condensed and IBM Plex Mono fonts
* Open Graph and structured data fallback
* Gutenberg block patterns

No required plugin or front-end build process is needed.

== Installation ==

1. Upload the installable ZIP under Appearance > Themes > Add New > Upload Theme.
2. Activate Xiangjinxin Industrial.
3. Open Appearance > Demo content and install the complete website package.
4. Review the RFQ recipient and privacy URL in the Customizer.
5. Configure a reliable WordPress mail transport.

== Frequently Asked Questions ==

= Does the theme require WooCommerce? =

No. The catalog and quotation workflow are built into the theme for non-checkout B2B sales.

= Does the theme store submitted enquiries? =

No. It sends enquiries through wp_mail() and removes temporary attachments after delivery.

= Can I edit products and pages? =

Yes. Products, specifications, pages, images, menus and theme settings remain editable in WordPress.
