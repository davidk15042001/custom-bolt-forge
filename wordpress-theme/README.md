# Xiangjinxin Fasteners WordPress Theme

1. Upload `xiangjinxin-fasteners.zip` in **Appearance → Themes → Add New → Upload Theme**.
2. Activate the theme.
3. Set the home page to display **Your latest posts** (the theme's `front-page.php` will render the landing page), or create a page and set it as the static homepage.
4. Create a menu in **Appearance → Menus** and assign it to **Primary Menu**.
5. Add products under **Products** and organize them using **Product Categories**.

RFQ submissions go to the WordPress administration email address. Configure a transactional mail plugin (for example, SMTP) in production to ensure delivery.
